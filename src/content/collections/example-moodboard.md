An example moodboard. Edit it in the dashboard (`/admin` → Moodboards → this
entry):

- **Title** and **tagline** introduce the moodboard at the top of `/shop/`.
- **Body** (this part) is optional long-form copy for the moodboard — the
  markdown supports headings, links, lists and images (`/images/…`).
- Curated items join this moodboard by setting their **Collection** field to
  this file's name (`example-moodboard`) in the Curated Items collection.

Only `published: true` moodboards reach `/shop/` — and curated items that
name an unpublished moodboard stay hidden with it.
